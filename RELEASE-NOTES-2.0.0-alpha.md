# Quantum YiJing International Academy — v2.0.0-alpha

## Purpose
This is the first multi-page development milestone for the v2.0 series. It is designed for the `v2-development` branch and must not be merged into production until the Cloudflare Preview has been reviewed.

## Added
- New bilingual `academy.html` page.
- Five-school academic structure.
- Educational philosophy and four-stage learning pathway.
- Responsive layouts for desktop, tablet and mobile.
- Google Form enquiry integration through the existing `script.js`.
- Mac installation helper with automatic backup of `index.html`.

## Changed
- The first Academy navigation link in `index.html` is changed from the homepage section to `/academy.html` by the installer.

## Preserved
- Existing v1.9.3 homepage sections, images, CSS and JavaScript.
- Existing Cloudflare Preview and production configuration.
- Existing Google Form URL.

## Status
Alpha development build. Test on Live Server and Cloudflare Preview before merging.
