# Install v2.8.1

1. Stay on the `v2-development` branch.
2. Copy the v2.8.1 update files into the repository, replacing matching files.
3. No Cloudflare D1 migration is required.
4. Commit with: `Fix v2.8 footer legal-link colors`
5. Push origin and wait for the Cloudflare Preview deployment.
6. Hard refresh the Preview page (`Ctrl + Shift + R`).
7. Verify Privacy Policy and Terms of Use are light/white in dark footers, while they remain strong blue on white enquiry-form backgrounds.
