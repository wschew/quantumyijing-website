# Release Notes — v3.2.0

## Secure SenangPay Integration
- Manual Integration API (Open API)
- HMAC-SHA256 server-side request signing
- HMAC-SHA256 Return/Callback verification
- Sandbox and Live modes
- Secure Cloudflare secret configuration
- Public post-registration Pay button
- Automatic D1 order/payment updates
- Gateway event audit trail
- Duplicate Return/Callback protection
- Emergency per-product payment disable SQL
- Settlement accounting remains separate from gateway authorization

## Not yet included
- Automatic PDF receipt/email generation
- Automatic SenangPay settlement-fee reconciliation
- Refund API automation
