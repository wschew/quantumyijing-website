# Quantum YiJing Website Version 1.9.1.1

## Installation
1. Extract the ZIP file.
2. Upload all files and the complete `images` folder to the root of the GitHub repository.
3. Replace the existing files when prompted.
4. Confirm that `research.css` is uploaded together with `index.html`, `styles.css`, `academic-programmes.css`, and `script.js`.
5. Wait for Cloudflare Pages to complete the production deployment.
6. Refresh the website with Command + Shift + R.

## Test
- Open both `https://quantumyijing.com` and `https://www.quantumyijing.com`.
- Click **Research & Innovation** in English and **研究与创新** in Chinese.
- Test the Research Philosophy, Published Works and Collaborate With Us buttons.
- Confirm both publication cover images appear.
