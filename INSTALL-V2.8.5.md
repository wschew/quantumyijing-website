# Install v2.8.5

1. Stay on `v2-development`.
2. Replace the matching files from the update package.
3. Commit with: `Standardize all footers and add Facebook for v2.8.5`
4. Push origin and wait for Cloudflare Preview.
5. Hard refresh with `Ctrl + Shift + R`.
6. Check Home, Events, Promotions, News, Products, Membership and Legal pages.

No D1 migration is required.
